Files in this folder are published at the site root, https://nanboy-ronan.github.io/FairMedFM-page/<file>
(this README is not). Use it for search engine ownership files:

- Google Search Console: add a URL-prefix property for https://nanboy-ronan.github.io/FairMedFM-page/, choose
  "HTML file" verification, and put the downloaded google<code>.html file here.
- Bing Webmaster Tools: put BingSiteAuth.xml here (or import the property from Google Search Console).

The <32 hex characters>.txt file is the IndexNow key; the Pages workflow uses it to notify Bing and other IndexNow
search engines of changed pages.
